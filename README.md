# Currículo de Visualização de Dados — tradução para o português

Tradução para o português de três partes do [Visualization Curriculum](https://github.com/uwdata/visualization-curriculum), o curso de visualização de dados com [Altair](https://altair-viz.github.io/) e [Vega-Lite](https://vega.github.io/vega-lite/) da Universidade de Washington.
## Conteúdo

| Notebook | Capítulo do original | Assunto |
|---|---|---|
| [`interaction_grupo_surpresa.ipynb`](interaction_grupo_surpresa.ipynb) | 6. Interaction | Seleções, consultas dinâmicas, arrastar e ampliar, visão geral + detalhe, filtragem cruzada |
| [`cartographic_visualization_grupo_surpresa.ipynb`](cartographic_visualization_grupo_surpresa.ipynb) | 7. Cartographic Visualization | GeoJSON e TopoJSON, mapas de pontos, de símbolos e coropléticos, projeções cartográficas |
| [`debugging_grupo_surpresa.ipynb`](debugging_grupo_surpresa.ipynb) | Altair Debugging Guide | Instalação, problemas de exibição, especificações e propriedades inválidas |
| [`intro_grupo_surpresa.md`](intro_grupo_surpresa.md) | Introduction | Apresentação do currículo e instruções de instalação |

Os notebooks na raiz são as versões finais. As pastas `interaction_grupo_surpresa/sections/` e `cartographic_visualization_grupo_surpresa/sections/` guardam as seções traduzidas separadamente, antes da união.

## Como abrir

Requer Python com Altair e um ambiente de notebooks:

```bash
pip install altair vega_datasets jupyterlab
```

```bash
jupyter lab
```
